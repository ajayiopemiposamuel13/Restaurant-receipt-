# Restaurant Receipt Generator

A Python script that asks the user for their order details and generates a formatted receipt.

## How it works
1. Prompts the user for the food name, price per item, and quantity.
2. Calculates the total cost.
3. Prints a clean, formatted receipt using dashes and the Naira (₦) symbol.

## Concepts used
- `float()` and `int()` for different data types.
- Basic arithmetic (`*`).
- `f-strings` for formatted text output.
